# ☕ Coffee Shop Sales Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze the sales performance of a coffee shop. The dashboard helps identify sales trends, top-performing products, store performance, and customer purchasing patterns to support better business decision-making.

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze overall sales performance of the coffee shop.
- Identify the highest-performing store locations.
- Determine the best-selling product categories and products.
- Analyze monthly sales trends.
- Identify peak sales hours.
- Present insights through an interactive Power BI dashboard.

---

## 🛠️ Tools Used

- Microsoft Excel
- Python (Google Colab)
- Pandas
- Power BI
- Power Query
- DAX (Data Analysis Expressions)

---

## 📂 Dataset

The dataset contains coffee shop transaction data, including:

- Transaction Date
- Transaction Time
- Store Location
- Product Category
- Product Detail
- Quantity Sold
- Unit Price
- Total Revenue

The data was cleaned and transformed using Power Query before being analyzed in Power BI.

## 🔍 Analysis Process

The analysis was conducted through the following steps:

1. Data Understanding using Python (Google Colab)
2. Exploratory Data Analysis (EDA)

The initial data exploration was performed using Python in Google Colab to understand the dataset before creating the dashboard.
The EDA included:

- Checking data types and dataset structure
- Generating descriptive statistics
- Identifying missing values
- Exploring product categories
- Understanding transaction distributions
- Preparing the data for visualization in Power BI
3. Data Cleaning & Transformation using Power Query
4. Data Modeling
5. Creating DAX Measures
6. Building Interactive Dashboard
7. Business Insight Generation
---

## 💡 Key Insights

- Coffee generated the highest revenue (270K), followed by Tea (196K) and Bakery (82K).
- Hell's Kitchen recorded the highest revenue (237K), although all three store locations showed relatively balanced performance.
- Sales increased consistently from January to June 2023, indicating positive business growth.
- Revenue peaked around 09:00–10:00 AM, making the morning the busiest sales period.
- The Top 10 products contributed significantly to total revenue, indicating that a small number of products drive most sales.

---

## 🚀 Business Recommendations

Based on the analysis, several recommendations can be made:

- Increase inventory for top-selling products during peak hours.
- Maintain adequate staffing during the morning rush (09:00–10:00 AM).
- Develop promotional strategies for lower-performing product categories.
- Monitor monthly sales trends to support inventory and operational planning.
- Continue optimizing product offerings based on customer purchasing behavior.
